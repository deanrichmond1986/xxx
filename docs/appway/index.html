Для установки данного приложения на ваш iPhone необходимо выполнить временный вход в наш общий аккаунт iCloud (Apple ID).

Инструкция по установке

Следуйте простым шагам для выхода из текущего Apple ID и входа в новый аккаунт.

  1. Откройте приложение «Настройки» на вашем iPhone
  2. Нажмите на ваше имя в верхней части экрана
  3. Прокрутите вниз и выберите «Выйти»
  4. Введите пароль вашего текущего Apple ID
  5. Подтвердите выход, выбрав «Выйти» в правом верхнем углу
  6. После выхода нажмите кнопку «Получить общий Apple ID» ниже и введите данные нового аккаунта. У вас будет 10 минут для входа
  7. Чтобы избежать проблем после обновления, при каждом входе в аккаунт выбирайте «Другие возможности», а на следующем экране — «Не улучшать».
