# Money Tap

Русская версия Telegram-игры из TapalkaBOT и автономная демоверсия для GitHub Pages.

## Открыть демоверсию через GitHub Pages

В настройках этого репозитория откройте **Settings → Pages**:

1. В **Source** выберите **Deploy from a branch**.
2. Выберите ветку **main**, папку **/docs** и нажмите **Save**.
3. Дождитесь успешного развёртывания; ссылка появится на странице Pages.

Демоверсия из `docs/` запускается без сервера и Telegram. Нажатия, энергия и улучшения работают в браузере. Прогресс сохраняется в `localStorage` этого браузера. Рейтинг демонстрационный; реальных выплат, проверки подписки и начислений в Telegram нет. Токен бота в сайт не включён.

## Полная версия

Go API, Python-бот и MongoDB требуют отдельного хостинга. GitHub Pages их не запускает. Инструкции подготовленной облачной среды: [README_RU.md](README_RU.md).

Локальный `config.json` с токеном исключён из Git. В репозитории есть только шаблон [config.example.json](config.example.json).

## Дизайн и разработка интерфейса

Основной интерфейс находится в `front/`: HTML, один общий CSS с токенами и `public/js/app.js`. Каталог `docs/` содержит его сгенерированную копию для GitHub Pages. Редактируйте общие экраны в `front/`, затем выполните `npm run build`; отдельный `docs/demo-api.js` обеспечивает локальную игру без сервера.

```bash
npm ci
python3 -m pip install -r tests/requirements.txt
npm run build
npm run check:format
npm run check:sync
npm run test:ui
```

Для тестов нужен Chromium (`CHROMIUM_PATH` позволяет указать исполняемый файл). Тестовый сервер поднимается автоматически на свободном локальном порту. Проверки покрывают игру, покупки, клавиатуру, доступность, пять размеров экрана, ошибки, отсутствие хранилища и работу нескольких вкладок. Отчёты и скриншоты находятся в `evidence/`.

Визуальные правила и связь с CSS-токенами: [DESIGN.md](DESIGN.md). Поведение общих компонентов и источники бизнес-правил: [UX-CONTRACT.md](UX-CONTRACT.md). Демо сохраняет прежний ключ прогресса `money-tap-demo-v1`, поэтому обновление дизайна не сбрасывает накопленные монеты.
