# AppWay original frontend preview

The uploaded index.html now supplies the original screen structure. The archive's app.js, catalog-content.js and styles.css remain unchanged. Deployment adapts only missing home-icon paths to the supplied logo, makes Cloudflare email decoding local to this subdirectory, and adds the existing preview adapter and viewport stylesheet. No original screen markup, text, or navigation is reconstructed.

Public entry: `/xxx/appway/index.html?preview=1`. The prior `preview.html?preview=1` URL redirects here. The project already supports the preview=1 query for viewing on desktop and non-iPhone devices. On desktop, the preview shows a 393 × 852 CSS-pixel display within an 8px rim (409 × 868px overall), with rounded corners, an island and a home indicator. The preview adapter scales the complete device uniformly to fit the window with a 24px outer margin; it never enlarges it above its natural size. On screens up to 500px wide, and in the Telegram surface, the external simulation is hidden and the UI fills the viewport. The stylesheet also provides visible focus and reduced-motion support. The preview query bypasses the original iPhone-only gate. CSS pixels are a logical device reference, not a claim of physical size on an uncalibrated monitor.

The uploaded instruction.mp4 is served by the original video player. The archive has no backend. The preview adapter gives explicit unavailable feedback for account issuance, rather than pretending to install apps or generating account credentials. Some screenshot references are absent from the archive; the adapter uses only supplied local screenshots and the original fallback renderer. Remote icons retain the application's own fallback.

Serve this directory with a static server, for example `python3 -m http.server 8093 --bind 127.0.0.1 --directory /workspace/xxx/docs/appway`. No package installation or build is needed. Static GitHub Pages publication is independent of the Money Tap root frontend.
