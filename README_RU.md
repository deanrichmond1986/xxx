# Money Tap — запуск на русском

Проект из `TapalkaBOT.zip` распакован в `/workspace/xxx`. Переведены пользовательский интерфейс, уведомления и приветствие Telegram-бота. API веб-интерфейса обращается к текущему серверу.

## Подготовленные компоненты

- Go 1.27.3, сервер и зафиксированные зависимости `go.mod` / `go.sum`.
- Python 3.12, виртуальное окружение и зависимости `requirements.txt`.
- MongoDB 8.0.16, локальная база данных в `/workspace/.tapalka/mongo-data`.
- Telegram-бот `@taptesttap_bot`, точка входа — `main.py`.

Повторная установка:

```bash
bash /workspace/.tapalka/scripts/install.sh
```

Запуск MongoDB, сервера и бота (команду можно повторять):

```bash
bash /workspace/.tapalka/scripts/start.sh
```

Сервер слушает только локальный адрес среды на порту 8080. Журналы находятся в `/workspace/.tapalka/logs/`. Запущенные процессы не сохраняются при создании новой машины: используйте инструкции запуска среды.

## Открытие игры в Telegram

Нужен публичный HTTPS-адрес, ведущий к этому серверу. Укажите его в переменной окружения `APP_URL` и перезапустите только процесс бота. До настройки адреса `/start` отвечает по-русски без кнопки, ведущей на старый сторонний сайт. Для локального HTTP нельзя создать рабочую кнопку Telegram Web App.

Существующий webhook отключён по разрешению пользователя без удаления ожидающих обновлений. Бот работает через polling. Не запускайте одновременно второй процесс для того же токена. Повторное отключение чужого webhook не входит в автоматический запуск.

Существующий `config.json` содержит локальные настройки и исключён из Git. Токен не встроен в `config.py`; при необходимости его можно переопределить переменной `TELEGRAM_BOT_TOKEN`. Не публикуйте файл конфигурации с токеном. Для новой установки используйте шаблон `config.example.json`.

## Проверено

- Загрузка русской страницы и интерфейса без Telegram (подсказка об открытии через бота).
- В среде DOM с имитацией Telegram: загрузка профиля, начало игры и клик.
- Реальные запросы к Go API и MongoDB: профиль, начисление монет и расход энергии, покупка улучшения, таймер, рейтинг. Временный тестовый профиль удалён.
- Telegram API `getMe`, отключение webhook и запуск polling. Отправка пользователю `/start` и открытие игры с телефона не проверялись.

В исходном API ошибки возвращаются как JSON с `ok: false`, в том числе с HTTP 200; проверка запуска учитывает это поведение. В архиве нет автоматических тестов Go.
